# Html Project - Interactive Motivation Page

## What does it do?

This is a simple, interactive web page built with HTML, CSS, and JavaScript. It's a beginner-friendly project that demonstrates how HTML, CSS, and JavaScript work together to create an interactive user experience. The page features a welcome message and an interactive button that triggers messages.

## Files Included

- **Index.html** - Main HTML file with structure and interactive button
- **Style.css** - External stylesheet for styling and layout
- **script.js** - JavaScript file for interactivity (referenced in HTML)

## Features

- Clean, centered layout with light blue background
- Welcome heading with personalized greeting
- Interactive button that responds to clicks
- Professional styling with Arial font
- Responsive button design with hover effects
- External CSS stylesheet for organized code

## How to use

1. Open `Index.html` in a web browser
2. Read the welcome message
3. Click the button to trigger the motivation message
4. The page displays styled content with an interactive element

## Technologies Used

- **HTML** - Page structure and elements
- **CSS** - Styling and layout (external stylesheet)
- **JavaScript** - Interactive functionality (button click handler)
